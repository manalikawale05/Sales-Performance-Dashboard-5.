# Sales Performance Dashboard — Power BI

## Project Overview
This project analyzes sales data using Microsoft Power BI to understand sales performance across different cities and products.

## Tools Used
- Microsoft Power BI Desktop
- Microsoft Excel
- DAX (Data Analysis Expressions)

## Dataset
The dataset contains 8 sales orders with the following columns:
- OrderID
- Product
- City
- Quantity
- Sales

## Dashboard Features
- Total Sales KPI
- Total Orders KPI
- City-wise sales analysis
- Product-wise sales analysis
- Sales summary table

## Key Insights
- Total Sales: ₹207,000
- Total Orders: 8
- Highest sales city: Mumbai
- Highest sales product: Laptop

## Files Included
- `Sales_Performance_Dashboard.pbix` — Power BI dashboard
- `Sales_Data.xlsx` — Excel dataset
